# Psychedelia
*Vintage Retro Fluid & Liquid Light Effects for After Effects*

**Psychedelia** is a GPU-accelerated After Effects plugin that emulates the organic, liquid-light projections and groovy "flower power" aesthetics of the 1970s. By combining multi-octave Fractional Brownian Motion (FBM) noise warp fields with dynamic spectrum drift, chromatic channel separation, customizable cellular flower arrays, and volumetric iridescent soap bubble shaders, Psychedelia makes it easy to create morphing psychedelic backgrounds, fluid light leaks, and retro-stylized motion graphic overlays.

---

## Quick Installation

1.  **Easiest Installation (Recommended):** The absolute easiest way to install is by using the official installer app. Download and install the **aescripts + aeplugins manager app** from:
    https://aescripts.com/learn/post/aescripts-aeplugins-manager-app

2.  **Manual Installation (Optional):** Close Adobe After Effects, locate the compiled plugin file `Psychedelia.aex` inside the downloaded archive, and copy-paste it directly into the After Effects Plug-ins folder:
    `C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Plug-ins\`

3.  **Apply the Effect:** Restart After Effects, select your target layer, and apply the plugin from the top menu bar path:
    **Effect -> Framesmith Labs -> Psychedelia**

## Creative Quick Start

*   **Soap Bubble Spheres:** Choose `Soap Bubble` under `Pattern Style`. This mode simulates 3D iridescent soap bubbles using custom volumetric center vignetting, dynamic Fresnel reflection, and complementary color absorption (transmission). Adjust `Palette Blend` to mix retro gradients with source image highlights.
*   **The Default Center Flower:** Set `Flower Density` to `0.0` and select `Groovy Flower` in `Pattern Style` to render a single, classic retro center flower. Use `Detail Scale` to resize it and `Dynamic Flower Colors` to animate its colors.
*   **Analog Liquid Flow:** Choose `Psychedelic Fold` under `Pattern Style`. Turn up `Flowing` or `Melting` under `Motion & Distortions` to slide and morph the noise lines.
*   **Hypnotic Motion Echoes:** Turn up `Tracers` under `Perception (Tracers)` and adjust `Spectrum Drift` to make your movement echo through vibrant gradient cycles.
*   **Logo/Text Overlay:** Apply Psychedelia directly to a transparent text/vector layer and ensure **Respect Source Alpha** is checked under the system settings.
