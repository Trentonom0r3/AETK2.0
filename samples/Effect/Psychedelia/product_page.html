Psychedelia is a fast, GPU-accelerated plugin designed to generate retro fluid noise patterns, organic flower power arrays, and volumetric iridescent soap bubbles. Instantly morph backgrounds, leak analog-style colors, and map dynamic distortions directly to text and vector layers.

Alpha Masked Text Layers

Ensure your letters remain perfectly anti-aliased and transparent while morphing textures shift dynamically within the boundaries of the source text.

Liquid Light Projections

Layer color separation shifts and perceptual motion tracers on top of text and solid layers to emulate analog video feedback loop effects.

Volumetric Soap Bubbles

Simulate 3D iridescent spherical soap bubbles using physical color transmission, dynamic Fresnel reflection, and central volumetric vignetting.

Quick Installation

1
Official Installer (Recommended)

The absolute easiest way to install is by using the official installer app.

Download the aescripts + aeplugins manager app >
2
Manual Installation (Optional)

Close After Effects, locate the compiled plugin file Psychedelia.aex inside the downloaded ZIP archive, and copy-paste it directly into your plugins directory:

C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Plug-ins\
3
Apply the Effect

Restart After Effects, select your target layer, and apply the plugin from the top menu bar path:

Effect -> Framesmith Labs -> Psychedelia
